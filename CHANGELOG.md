# Changelog

All notable changes to this project are documented here. Snapshot releases are
named by the data date (`YYYY.MM.DD`).

## [2026.11.02]

### Added
- Citation metadata (`CITATION.cff`) for reproducible references.
- Contribution guidelines and issue/PR templates with a data-provenance workflow.
- README badges, hero figure, outputs table, "what to do first" section, and
  citation guidance.

### Changed
- README headline figures and findings aligned to the 2026-11-02 snapshot.

## [2026.10.31]

### Added
- Live phishing, payload (URLhaus-derived), and C2 feed collection.
- Public Suffix List-based parsing with private platform-suffix separation.
- Annual registry data (2020–2026) and Wayback payload/C2 history.
- Four-tier risk model, evidence-confidence score, and blocklist suitability.
- Generated analysis report and 12 figures.
- Weekly refresh workflow.
